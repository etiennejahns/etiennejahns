Verarbeitungsübersicht

Die Website verwendet keine Analyse-, Tracking- oder Marketing-Werkzeuge. Es werden keine Werbung-Cookies gesetzt. Die folgende Übersicht fasst die Verarbeitung nach Art, Zweck, Rechtsgrundlage, Weitergabe und Speicherdauer zusammen.

Datenarten
Server-Logdaten beim Abruf (IP-Adresse, Zeitpunkt, abgerufene Ressource, Browserkennung/User-Agent, ggf. Referrer). Keine Datenübermittlung bei Webfonts, E-Mail-Link, Quiz und Bot.
Zwecke
Bereitstellung und Sicherheit der Website (Logdaten); Nutzerführung im Browser (lokal gespeicherter Einstiegs-/Banner-Status).
Rechtsgrundlage
Hosting-Logdaten: Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse). Lokale Speicherung: technisch notwendig, ohne Übermittlung an Server.
Weitergabe an Dritte
Die Website wird technisch über GitHub Pages, einen Dienst der GitHub Inc., bereitgestellt. Beim Aufruf der Website können technisch erforderliche Verbindungsdaten durch GitHub verarbeitet werden. Eine Weitergabe zu Werbe- oder Trackingzwecken erfolgt nicht.
Speicherdauer
Server-Logdaten werden von GitHub gemäß dessen Datenschutzinformationen verarbeitet. Lokale Speicherung: bis zum Löschen der Browserdaten.

Hosting

Diese Website wird über GitHub Pages, einen Dienst der GitHub Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA, bereitgestellt. Beim Aufruf der Website werden technisch erforderliche Daten verarbeitet, um die Website auszuliefern und die Sicherheit sowie Stabilität des Dienstes zu gewährleisten. Hierzu können insbesondere die IP-Adresse, Datum und Uhrzeit des Zugriffs, Informationen zum verwendeten Browser und Betriebssystem sowie die aufgerufene Ressource gehören. Die Verarbeitung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an der sicheren und zuverlässigen Bereitstellung dieser Website). Nähere Informationen zur Verarbeitung und Speicherdauer technischer Serverprotokolle durch GitHub finden Sie in den Datenschutzinformationen von GitHub.

Durch die Nutzung von GitHub Pages kann eine Verarbeitung personenbezogener Daten auf Servern in Staaten außerhalb der Europäischen Union erfolgen, insbesondere in den Vereinigten Staaten von Amerika. Für Datenübermittlungen in die USA stützt sich GitHub auf geeignete Garantien gemäß Art. 44 ff. DSGVO. Weitere Informationen finden Sie in den Datenschutzinformationen von GitHub.

Lokale Speicherung im Browser

Es werden keine Tracking-Cookies gesetzt. Im lokalen Speicher des Browsers wird ausschließlich abgelegt, ob der Einstieg abgeschlossen und ob das Cookie-Banner geschlossen wurde. Diese Angaben verlassen das Gerät nicht und lassen sich durch Löschen der Browserdaten entfernen.
